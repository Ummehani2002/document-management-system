Internal demo

Document Management System

One place for company project files — filed in the right folder, easy to find, and safe if something is deleted by mistake.

What this is

Stop hunting through email and shared folders

For document controllers

Upload once. The system places the file in the correct folder from the file name and the title on the document.

For the project team

Open your company, then search or browse folders. You only see what you are allowed to see.

For managers

Each company and project stays separate. Construction and trading are not mixed.

For everyone

View or download the PDF. The original stays in the system.

How you enter

Three simple steps

1

Business type

Choose Trading or Construction on the home page.

2

Company

Open your company. After that, everything is only for that company.

3

Project

Work inside the project number (for example PSE20251015).

Auto filing

The file name and title choose the folder

  • WIR → Work Inspection  ·  MIR → Material Inspection Request
  • Minutes / MOM → MOM  ·  PREQ / PQ → Prequalification
  • SD / shop drawing submittal → Shop Drawing  ·  MAT / MB → Material Submittal
  • DT → Transmittal  ·  LTR / LOR → Letters
  • Also: Method Statement, BOQ, NCR, CVI, RFI, TOC, Variation, O&M, and the other folders you already use.

If the name is not clear, you can still pick the folder when you upload.

Finding files

Folders or Search

Left-side folders

Browse like a filing cabinet. Open Work Inspection, MOM, Shop Drawing, and so on for this company and project.

Search

Type part of the file name (WIR, MIR, 00015). After a file is indexed, you can also search a word that appears inside the PDF.

Safety and access

Nothing disappears by accident

Trash

Delete moves the file to Trash. An admin can restore it.

Projects

If a project number is deleted by mistake, creating the same number brings that project back. Files stay in Trash until you restore them.

User access

People only see the companies, projects, and folders they are given.

Activity log

We can see who uploaded or deleted a file, and when.
